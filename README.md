# 🌱 Agrelp - Sistema de Gerenciamento Agrícola

O **Agrelp** é um sistema web desenvolvido com o objetivo de auxiliar no gerenciamento de uma propriedade rural, permitindo o controle de máquinas, sementes, materiais, defensivos agrícolas e demais recursos utilizados no dia a dia da fazenda.

O projeto foi desenvolvido utilizando **Java com Spring Boot**, com páginas renderizadas através do **Thymeleaf**, banco de dados relacional e uma interface personalizada para facilitar a navegação e o uso do sistema.

---

## 📌 Sobre o projeto

O sistema foi pensado para centralizar informações importantes de uma fazenda em uma única aplicação, facilitando o cadastro, visualização, edição e controle dos principais recursos agrícolas.

Através do Agrelp, é possível organizar melhor os dados da propriedade, reduzir processos manuais e tornar a gestão mais prática e eficiente.

---

## 🚀 Funcionalidades

- Dashboard com informações gerais do sistema;
- Cadastro de máquinas agrícolas;
- Listagem de máquinas em formato de tabela e cards;
- Exibição de imagens das máquinas cadastradas;
- Cadastro de sementes;
- Cadastro de materiais;
- Cadastro de defensivos agrícolas;
- Controle de quantidade em estoque;
- Organização dos recursos por categorias;
- Interface com sidebar personalizada;
- Páginas dinâmicas utilizando Thymeleaf;
- Integração com banco de dados;
- Operações de cadastro, listagem, edição e exclusão.

## 🖥️ Telas do sistema

Nesta seção estão algumas das principais telas presentes no sistema **Agrelp**.

### 📊 Dashboard

O dashboard apresenta informações gerais do sistema, como a quantidade de máquinas e outros registros cadastrados.

### 🚜 Máquinas

A área de máquinas permite cadastrar, listar, visualizar e gerenciar máquinas agrícolas utilizadas na propriedade.

### 🛠️ Ferramentas

A tela de ferramentas permite cadastrar, listar e gerenciar ferramentas utilizadas nas atividades da propriedade rural.

### 📦 Estoque

O sistema também possui áreas voltadas ao controle de estoque, incluindo sementes, materiais e defensivos agrícolas.

---

## 🧩 Principais módulos

O sistema é dividido em módulos para facilitar a organização e o gerenciamento das informações da propriedade rural.

### 🚜 Máquinas

Responsável pelo cadastro e controle de máquinas agrícolas, incluindo dados como nome, modelo, descrição, quantidade e imagem.

### 🛠️ Ferramentas

Responsável pelo cadastro e controle de ferramentas utilizadas no dia a dia da propriedade, facilitando a organização e o acompanhamento dos itens disponíveis.

### 🌾 Sementes

Permite cadastrar sementes utilizadas na propriedade, incluindo informações como nome, fabricante, quantidade e demais dados relevantes.

### 🧰 Materiais

Área destinada ao controle de materiais utilizados no ambiente agrícola.

### 🧪 Defensivos Agrícolas

Permite o cadastro de defensivos agrícolas, contendo informações como nome, categoria, descrição, quantidade, fabricante e preço.

---

## 🎨 Interface

A interface do sistema foi personalizada com foco em usabilidade, utilizando uma sidebar para navegação entre as páginas e estilos próprios em CSS.

O objetivo visual do projeto é oferecer uma experiência simples, organizada e fácil de utilizar.

---

## 📈 Objetivo do sistema

O objetivo principal do **Agrelp** é facilitar a gestão de recursos agrícolas, permitindo que o usuário tenha maior controle sobre os itens utilizados na fazenda.

Com isso, o sistema contribui para uma administração mais eficiente, organizada e digitalizada.
